# Audio Sources

- `bgm-rumble-jungle.ogg`: converted from "Rumble Jungle" by Pro Sensory / Alex McCulloch on OpenGameArt. License: CC0.
- `bgm-home-calm.ogg`: "Calm Track" by pmiller on OpenGameArt. License: CC0.
- `bgm-triassic-jungle.wav`, `bgm-volcanic-ridge.wav`, `bgm-crystal-cavern.wav`, `bgm-storm-coast.wav`: generated locally for this project as short procedural loop BGM assets.
- `sfx-*.mp3`: selected from 効果音ラボ. The project uses local copies of the downloaded files; no runtime hotlinking.

OpenGameArt source assets above are public domain / CC0. 効果音ラボ assets are free for commercial use under the site's terms; credit is not required, but redistribution as a standalone sound-material pack is not intended.
