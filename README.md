# DINO RUSH: EVOLUTION

スマホ縦持ち `390x844` を主基準にした、恐竜進化サバイバー系Webゲームです。

## プレイ

静的ファイルだけで動作します。ローカル確認時は次のコマンドで起動します。

```powershell
python -m http.server 4173
```

ブラウザで `http://localhost:4173/` を開いてください。

## 現在の実装

- タイトル画面、ホーム画面、ステージ選択、ショップ、図鑑、ハイスコア、設定
- ノーマル、ハード、エンドレスの3モード
- DNAポイントによるスキル・恐竜解放
- 恐竜、スキル、進化、敵、ボス、マップを `data/*.json` で管理
- localStorage による進行状況、解放状況、設定、エンドレス記録の保存
- BGM、効果音、タイトルムービー、2Dイラスト素材

## セーブデータ

セーブキーは `dinoRushEvolution.save.v1` です。

新しい恐竜、スキル、進化、マップ、モードを追加する場合は、既存キーを変更せず、必要な項目を追加してください。`src/game.js` の `loadMeta()` は未保存項目にデフォルト値を補完する設計のため、通常の追加実装では既存セーブは維持されます。

## 拡張方針

- 戦闘・表示の追加は、可能な限り `data/*.json` のID参照で行う
- ランタイム素材は `assets/` 配下の用途別フォルダへ配置する
- 生成元シートや作業用素材は `assets/sheets/` に置き、Git管理からは外す
- 背景、アイテム、敵、プレイヤーは同じワールド座標で扱い、地面レイヤーにパララックスを戻さない
- 敵の移動速度はプレイヤー移動状態に依存させない
